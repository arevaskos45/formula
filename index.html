Физика

Закон всемирного тяготения

F = G · m1m2 / r2

F — сила тяготения, G — гравитационная постоянная, m₁ и m₂ — массы тел, r — расстояние между ними.

Где применяется: расчёт силы притяжения между телами.
Физика

Закон Ома

I = U / R

I — сила тока, U — напряжение, R — сопротивление.

Где применяется: расчёты в электрических цепях.
Физика

Скорость движения

v = s / t

v — скорость, s — пройденный путь, t — время движения.

Как искать: «скорость», «путь», «время», «движение».
Математика

Дискриминант

D = b2 − 4ac

D — дискриминант, a, b, c — коэффициенты квадратного уравнения ax² + bx + c = 0.

Где применяется: для определения количества корней квадратного уравнения.
Математика

Корни квадратного уравнения

x = (−b ± √D) / 2a

x — корень уравнения, b и a — коэффициенты, D — дискриминант.

Где применяется: решение квадратных уравнений.
Геометрия

Теорема Пифагора

c2 = a2 + b2

c — гипотенуза, a и b — катеты прямоугольного треугольника.

Где применяется: поиск стороны прямоугольного треугольника.
Геометрия

Площадь круга

S = πr2

S — площадь круга, π — число пи, r — радиус круга.

Где применяется: расчёт площади круглых фигур.
Геометрия

Площадь треугольника

S = ½ah

S — площадь, a — основание, h — высота, проведённая к основанию.

Как искать: «площадь треугольника», «основание», «высота».
